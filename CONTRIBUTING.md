# Contributing

Issues and pull requests are welcome **here**, in this repository.

## Please know this first

- **This project uses AI assistance.** It was made with a lot of help from an AI (Anthropic's Claude), and
  contributions may be reviewed or edited with AI help too.
- **Never send any of it to Dusklight.** Dusklight does not accept contributions that are primarily AI-generated.
  Don't copy code from here into Dusklight pull requests, and don't report this mod's bugs to the Dusklight team.
  If you want to help Dusklight itself, follow their own rules.
- **No game files.** Never commit anything from the games or made from them: `mods/hdfeatures/res/`,
  `mods/hdfeatures/overlay/`, the mod's `mod_data` folder, `hdf-convert` outputs, `.dusk` packages, images, text
  or data taken from the games. The `.gitignore` covers the usual ones. The one exception is the README's short
  gameplay recording, `docs/showcase.gif`, which is pinned in `tools/dist/make_repo.py`.
- **No personal details.** Keep your user name, folder paths and e-mail out of code, logs and screenshots.

## Pull requests

- Keep them small and say what you tested (and how: in the game, or only built).
- Build instructions: [BUILDING.md](BUILDING.md).
- By sending a pull request you agree that your work is shared under this project's [MIT License](LICENSE).

See also: [DISCLAIMER.md](DISCLAIMER.md).
